## ⚠️ Проблемы, обнаруженные в реальном CSV

### **Критическая: Двойное экранирование дат**

В приложенном `audit-log_1787231149141.csv` (строка 2):
```csv
42,"""2026-08-20T12:46:34.864Z""",tiy247@mail.ru,...
```

Дата обёрнута в **тройные кавычки**: `"""2026-08-20..."""`. Это означает:
1. `serializeAuditCsvCell` вернула строку с кавычками
2. Затем она была снова обёрнута в кавычки при записи в CSV

**Причина:** В `auditCsv.ts` строка 24:
```typescript
return /[",\r\n]/.test(spreadsheetSafe)
  ? `"${spreadsheetSafe.replace(/"/g, '""')}"`
  : spreadsheetSafe;
```

Если `spreadsheetSafe` уже содержит кавычки (например, из JSON.stringify), они удваиваются. Но в `routes/admin/auditLog.ts` строка 107:
```typescript
const line = headers.map((h) =>
  serializeAuditCsvCell((r as Record<string, unknown>)[h]),
);
```

Если `createdAt` приходит как строка (не Date), она может содержать кавычки из предыдущей обработки.

**Решение:** Проверить, приходит ли `createdAt` как Date или как строка. Если строка — убрать кавычки перед сериализацией.

## 🔧 Что нужно исправить

### **P0: Двойное экранирование дат**

**Файл:** `artifacts/api-server/src/routes/admin/auditLog.ts`

**Проблема:** `createdAt` может приходить как строка с кавычками из БД.

**Решение:**
```typescript
// В serializeAuditCsvCell добавить проверку на строку с кавычками
export function serializeAuditCsvCell(value: unknown): string {
  if (value == null) return "";

  const raw =
    value instanceof Date
      ? value.toISOString()
      : typeof value === "object"
        ? JSON.stringify(value)
        : String(value).replace(/^"|"$/g, ""); // Убрать внешние кавычки

  // ... остальная логика
}
```

Или в `routes/admin/auditLog.ts`:
```typescript
const line = headers.map((h) => {
  const v = (r as Record<string, unknown>)[h];
  // Если строка начинается и заканчивается кавычкой — это уже сериализованное значение
  const cleanValue = typeof v === "string" && v.startsWith('"') && v.endsWith('"')
    ? JSON.parse(v) // Распарсить обратно в Date/object
    : v;
  return serializeAuditCsvCell(cleanValue);
});
```
