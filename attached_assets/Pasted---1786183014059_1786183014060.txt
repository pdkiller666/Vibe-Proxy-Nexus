## ❌ НЕ применённые фиксы (критично)

### 1. Middleware всё ещё patch'ит `res.send`, не `res.on('finish')`

**Текущее состояние** (из последнего извлечения auditLog.ts):
```typescript
export function auditLogMiddleware() {
  return async (req, res, next) => {
    const startedAt = Date.now();
    const originalSend = res.send.bind(res);
    res.send = function (this: Response, body?: unknown): Response {
      // ... логирование ...
      return originalSend(body);
    };
    next();
  };
}
```

**Это та же самая проблема**, из-за которой бан пользователя не отображается в журнале. Все маршруты с `res.status(204).end()` или `res.sendStatus(204)` **по-прежнему не логируются**:
- `POST /admin/users/:userId/ban`
- `POST /admin/users/:userId/unban`
- `POST /admin/users/:userId/force-logout`
- `DELETE /admin/users/:userId`
- `DELETE /admin/plans/:planId`
- `DELETE /admin/vpn-keys/:keyId`
- `DELETE /admin/invite-links/:linkId`

### 2. `normalizeRoutePath` не нормализует числовые сегменты

**Текущее состояние:**
```typescript
function normalizeRoutePath(path: string): string {
  return path
    .split("/")
    .map((seg) => (seg.startsWith(":") ? ":id" : seg))  // Только :xxx → :id
    .join("/");
}
```

**Проблема:** Если `req.route` недоступен (edge case), путь `/admin/users/42/ban` не совпадёт с `POST /admin/users/:id/ban` в ACTION_MAP.

```typescript
export function auditLogMiddleware() {
  return async (
    req: Request,
    res: Response,
    next: NextFunction,
  ): Promise<void> => {
    const startedAt = Date.now();

    // Используем событие 'finish' вместо patch res.send
    // Это ловит ВСЕ ответы: res.json(), res.send(), res.status(204).end(), res.sendStatus(204)
    res.on('finish', () => {
      if (
        res.statusCode >= 200 &&
        res.statusCode < 300 &&
        ["POST", "PATCH", "PUT", "DELETE"].includes(req.method)
      ) {
        const durationMs = Date.now() - startedAt;
        void logAdminAction(req, res, durationMs).catch((err) => {
          logger.error(
            { err, path: req.path },
            "auditLog: failed to log action",
          );
        });
      }
    });

    next();
  };
}
```

### Приоритет #2: Исправить normalizeRoutePath

**Найти:** функцию `normalizeRoutePath` (примерно строки 114-120)

**Заменить на:**
```typescript
function normalizeRoutePath(path: string): string {
  return path
    .split("/")
    .map((seg) => {
      if (seg.startsWith(":")) return ":id";
      if (/^\d+$/.test(seg)) return ":id";  // Числовые сегменты → :id
      return seg;
    })
    .join("/");
}
```
